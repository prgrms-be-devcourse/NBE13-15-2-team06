# 냉장고를 부탁해

집에 우유가 얼마나 남았는지, 어떤 식재료를 먼저 써야 하는지 확인할 수 있는 냉장고 관리 서비스입니다. 냉장고에 있는 식재료의 수량과 유통기한을 기록하고, 함께 사는 사람과 공용 식재료를 관리할 수 있도록 백엔드 API를 개발하고 있습니다.

## 개발 범위

- **냉장고 그룹** — 그룹을 만들고 구성원을 관리합니다.
- **식재료 관리** — 식재료를 등록하고 수량, 단위, 보관 방식, 유통기한을 관리합니다. 사용한 만큼 수량을 차감하고, 개인용과 공용 식재료를 구분합니다.
- **검색과 조회** — 식재료를 이름으로 검색하거나 유통기한순으로 정렬하고, 기한이 임박한 식재료를 모아 봅니다.
- **변경 이력과 알림** — 식재료 사용·폐기 등의 변경 이력을 확인하고, 유통기한이 다가오는 식재료의 알림을 확인합니다.

현재는 공통 개발 환경을 구성하고 도메인별 엔티티, DTO, 리포지토리를 작성하는 단계입니다.

## 기술 스택

- Java 21, Spring Boot
- Spring Data JPA, Spring Security
- MySQL, Gradle

## 로컬 실행

1. 프로젝트 루트의 `.env.example`을 참고해 `.env`를 만들고 로컬 DB 접속 정보를 설정합니다.
2. 로컬 MySQL에 `fridge` 데이터베이스를 준비하고, 해당 DB에서 `src/main/resources/db/schema.sql`을 실행해 테이블을 생성합니다.
3. IntelliJ에서 `FridgeApplication`을 실행합니다.

## 협업 방식

`main`은 통합 브랜치입니다. 인증, 냉장고 그룹, 식재료 등 도메인별 기능 브랜치에서 작업하고, 검토할 수 있는 작업 단위가 준비되면 `main`으로 PR을 올립니다. PR은 팀 협업 시간에 함께 검토하고, 병합은 지정된 담당자가 진행합니다.

커밋 메시지에는 작업에 맞춰 `feat`, `fix`, `docs`, `refactor`, `chore` 접두사를 사용합니다.
